# Jira Exporter

这是一个 Jira 导出浏览器工具，目标是把导出入口做成更容易演示和使用的 Chrome 工具。

## 目录内容

- `manifest.json`：扩展清单
- `popup.html`：工具入口
- `content.js`：在 Jira 页面注入“导出当前单”按钮
- `shared.js`：导出逻辑和共享工具函数

## 当前能力

- 当前页面会自动识别 Jira 地址
- 当前单号可以直接导出
- 输入 JQL 后可以直接导出
- 生成的报告会直接下载为一个 ZIP 包
- ZIP 里包含 `summary.html`、`manifest.json`、各单的 JSON 备份和附件文件
- 图片会直接内嵌预览，日志 / 文本会展开显示，二进制附件会一起打包进去

## 现在怎么试

1. 打开 Chrome 的扩展程序管理页
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 指向这个目录 `jira_exporter_extension`
5. 在 Jira 页面里点击右下角的“导出当前单”

## 说明

- 扩展会优先从当前打开的 Jira 页面自动读取地址，支持纯 IP、域名和带路径前缀的地址
- 累计导出次数会保存在浏览器本地
- 如果 Jira 页面刚加载时右下角按钮还没出现，稍等一下或刷新页面，按钮会自动挂载
- 默认导出文件会在浏览器下载位置下生成一个 `jira_exporter_exports/export_时间戳.zip`
- 解压后会得到同名目录，里面有 `summary.html` 和附件
